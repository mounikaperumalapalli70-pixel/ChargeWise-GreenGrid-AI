Methodology

Required energy = capacity × (target − current SOC) / 100. Each slot: total power ≤ solar + grid import limit; each EV ≤ min(vehicle, charger kW); at most N chargers active. Optimized ordering uses slack = slots left − energy left ÷ (power × slot hours); EVs with slack ≤ 2 are forced, others wait if a cheaper/solar slot exists before departure. This is a transparent rule-based optimizer, not machine learning. All telemetry is simulated.
